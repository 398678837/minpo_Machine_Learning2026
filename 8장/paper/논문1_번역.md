# 논문 1 상세 번역/해설: Induction of Decision Trees

> **원제**: Induction of Decision Trees
> **저자**: J. Ross Quinlan (1986)
> **학술지**: Machine Learning, Vol. 1, No. 1, pp. 81-106

---

## 1. 서론 (Introduction)

### 배경과 동기

Quinlan은 기계학습의 핵심 과제 중 하나로 **개념 학습(Concept Learning)**을 제시한다. 개념 학습이란, 주어진 사례(examples)들로부터 일반적인 규칙(rules)을 유도하는 과정이다. 이때, 각 사례는 속성(attributes)의 집합으로 기술되며, 미리 정의된 클래스(class) 중 하나에 속한다.

의사결정나무는 이러한 개념 학습을 수행하는 가장 직관적이고 해석 가능한 방법 중 하나이다. 트리의 각 내부 노드(internal node)는 하나의 속성에 대한 테스트를 나타내고, 각 분기(branch)는 해당 테스트의 결과에 해당하며, 각 리프 노드(leaf node)는 클래스 레이블을 나타낸다.

### 핵심 질문

논문이 다루는 핵심 질문은 다음과 같다:
- **어떻게 훈련 사례로부터 효율적으로 의사결정나무를 구축할 것인가?**
- **구축된 트리가 새로운 사례에 대해 정확하게 분류할 수 있는가?**
- **트리의 복잡도를 어떻게 제어할 것인가?**

## 2. ID3 알고리즘의 핵심 원리

### 2.1 정보 엔트로피 (Information Entropy)

Quinlan은 Claude Shannon의 정보 이론에서 엔트로피 개념을 차용한다. 집합 S에 c개의 클래스가 있고, 각 클래스 i의 비율이 p_i일 때, 집합 S의 엔트로피는 다음과 같이 정의된다:

```
H(S) = -SUM_{i=1}^{c} p_i * log2(p_i)
```

**직관적 해석**: 엔트로피는 집합의 "무질서도" 또는 "불확실성"을 측정한다. 모든 사례가 동일한 클래스에 속하면 엔트로피는 0(완전한 질서)이고, 모든 클래스가 동일한 비율로 존재하면 엔트로피가 최대(최대 불확실성)가 된다.

**예시**: 이진 분류에서 양성:음성 = 9:5인 경우
```
H(S) = -(9/14) * log2(9/14) - (5/14) * log2(5/14)
     = -(0.643) * (-0.637) - (0.357) * (-1.486)
     = 0.410 + 0.531
     = 0.940
```

### 2.2 정보 이득 (Information Gain)

속성 A로 집합 S를 분할할 때의 정보 이득은 분할 전후의 엔트로피 차이로 정의된다:

```
IG(S, A) = H(S) - SUM_{v in Values(A)} (|S_v| / |S|) * H(S_v)
```

여기서 S_v는 속성 A의 값이 v인 부분집합이다.

**직관적 해석**: 정보 이득은 특정 속성으로 분할했을 때 "얼마나 불확실성이 줄어드는가"를 측정한다. 정보 이득이 클수록 해당 속성이 분류에 더 유용하다는 것을 의미한다.

### 2.3 ID3 알고리즘 절차

ID3 알고리즘의 재귀적 절차는 다음과 같다:

```
함수 ID3(S, Attributes):
    1. 노드 N을 생성한다.
    2. 만약 S의 모든 사례가 동일한 클래스 C에 속하면:
       - N을 클래스 C를 가진 리프 노드로 반환한다.
    3. 만약 Attributes가 비어 있으면:
       - N을 S에서 가장 빈번한 클래스를 가진 리프 노드로 반환한다.
    4. 그렇지 않으면:
       a. Attributes 중 정보 이득이 가장 큰 속성 A를 선택한다.
       b. N의 테스트 속성을 A로 설정한다.
       c. A의 각 값 v에 대해:
          - S_v = {s in S | s의 A값 = v}
          - 만약 S_v가 비어 있으면:
            - S에서 가장 빈번한 클래스를 가진 리프 노드를 추가한다.
          - 그렇지 않으면:
            - ID3(S_v, Attributes - {A})를 재귀 호출하여 자식 노드로 추가한다.
    5. N을 반환한다.
```

## 3. 실험 결과 분석

### 3.1 체스 종반 문제 (Chess Endgame)

Quinlan은 킹-룩 대 킹-나이트(KR vs KN) 체스 종반 문제에서 ID3를 평가하였다. 데이터셋은 체스 판의 상태를 기술하는 속성들로 구성되며, 목표는 특정 상태에서 백(white)이 승리할 수 있는지를 분류하는 것이다.

실험 결과, ID3는 비교적 적은 수의 훈련 사례만으로도 높은 분류 정확도를 달성하였다. 그러나 훈련 데이터의 크기가 증가할수록 트리의 복잡도도 함께 증가하며, 특정 시점 이후에는 정확도 향상이 미미해지는 현상이 관찰되었다.

### 3.2 노이즈가 있는 데이터

실세계 데이터에는 측정 오류, 레이블 오류 등의 노이즈가 존재한다. Quinlan은 노이즈가 있는 데이터에서 ID3가 불필요하게 깊은 트리를 생성하여 노이즈까지 학습하는 현상(과적합)을 보고하였다.

이에 대한 해결책으로 **가지치기(pruning)**를 제안한다:
- 완전히 성장한 트리에서, 각 하위 트리를 해당 노드에서 가장 빈번한 클래스의 리프 노드로 대체한다.
- 대체 후 검증 데이터에서의 오류율이 증가하지 않으면 대체를 확정한다.
- 이 과정을 반복하여 불필요한 가지를 제거한다.

## 4. 편향 분석 (Bias Analysis)

### 4.1 귀납적 편향 (Inductive Bias)

ID3의 귀납적 편향은 두 가지 측면을 가진다:

1. **선호 편향 (Preference Bias)**: 짧은 트리를 긴 트리보다 선호한다. 이는 정보 이득이 높은 속성을 먼저 선택함으로써 자연스럽게 발생한다.

2. **언어 편향 (Language Bias)**: 축 정렬(axis-aligned) 분할만 가능하다. 즉, 각 노드에서 하나의 속성에 대한 테스트만 수행할 수 있으며, 여러 속성의 선형 조합에 의한 분할은 불가능하다.

### 4.2 카디널리티 편향 (Cardinality Bias)

정보 이득 기준의 심각한 문제 중 하나는 **고카디널리티 속성에 대한 편향**이다. 예를 들어, 각 사례마다 고유한 값을 가지는 ID 속성은 완벽한 정보 이득을 제공하지만, 새로운 사례에 대해서는 전혀 일반화 능력이 없다.

Quinlan은 이 문제를 인식하고, 후속 연구에서 **정보 이득 비율(Gain Ratio)**을 제안하였다:

```
GainRatio(S, A) = IG(S, A) / SplitInfo(S, A)

SplitInfo(S, A) = -SUM_{v} (|S_v|/|S|) * log2(|S_v|/|S|)
```

SplitInfo는 속성 A 자체의 엔트로피로, 카디널리티가 높을수록 값이 커져서 정보 이득을 정규화하는 역할을 한다.

## 5. 연속형 속성의 처리

ID3의 기본 형태는 이산형(categorical) 속성만 처리할 수 있다. 연속형(continuous) 속성을 처리하기 위해, Quinlan은 **이진 분할(binary split)** 방법을 제안한다:

1. 연속형 속성의 값을 정렬한다.
2. 인접한 서로 다른 클래스의 값 사이에 후보 분할점(threshold)을 설정한다.
3. 각 후보 분할점에 대해 정보 이득을 계산한다.
4. 정보 이득이 최대인 분할점을 선택한다.

```
속성 A의 값: 1.2, 2.5, 3.1, 4.8, 5.3, 6.7
클래스:      +    +    -    -    +    -

후보 분할점: 2.8 (2.5와 3.1 사이), 4.15 (3.1과 4.8 사이), 5.05 (4.8과 5.3 사이), 6.0 (5.3과 6.7 사이)

각 분할점에 대해 IG 계산 후 최대값 선택
```

## 6. 결측값 처리 (Missing Values)

실세계 데이터에서 결측값은 빈번하게 발생한다. Quinlan은 결측값 처리를 위한 여러 전략을 논의한다:

1. **결측값 무시**: 해당 사례를 분할에서 제외하고, 남은 사례들로만 정보 이득을 계산한다.
2. **분수적 분배(Fractional Distribution)**: 결측값을 가진 사례를 속성 값의 비율에 따라 각 분기에 분수적으로 분배한다.
3. **최빈값 대체**: 결측값을 해당 속성의 최빈값(most common value)으로 대체한다.

---

## 7. 윈도우 기법 (Windowing)

대규모 데이터셋에 대한 효율적 학습을 위해, Quinlan은 **윈도우 기법(windowing)**을 제안한다:

1. 전체 훈련 데이터에서 랜덤하게 부분집합(윈도우)을 추출한다.
2. 윈도우에 대해 트리를 구축한다.
3. 구축된 트리로 전체 데이터를 분류하고, 오분류된 사례를 윈도우에 추가한다.
4. 오분류 사례가 없을 때까지 2-3을 반복한다.

이 방법은 대규모 데이터셋에서의 학습 효율을 높이며, 동시에 오분류 사례에 집중함으로써 어려운 사례에 대한 학습을 강화한다.

## 8. 핵심 요약 및 의의

### 본 논문의 핵심 메시지

1. **정보 이론의 기계학습 적용**: Shannon의 엔트로피 개념을 분류 문제의 속성 선택에 성공적으로 적용하였다.
2. **탐욕적 전략의 유효성**: 각 단계에서 지역적으로 최적인 속성을 선택하는 탐욕적 전략이 실제로 우수한 분류 트리를 생성한다.
3. **과적합의 인식과 대응**: 트리의 과적합 문제를 인식하고 가지치기라는 체계적 해결책을 제시하였다.
4. **실용적 고려사항**: 연속형 속성, 결측값, 노이즈 등 실세계 데이터의 복잡성을 고려한 확장 방안을 논의하였다.

### 후속 연구에의 영향

본 논문은 이후 다음과 같은 핵심 연구들의 직접적 토대가 되었다:
- **C4.5 (Quinlan, 1993)**: 정보 이득 비율, 향상된 가지치기, 연속 속성 처리 개선
- **CART (Breiman et al., 1984)**: 지니 불순도 기반의 이진 분할 트리 (독립적으로 발전)
- **랜덤 포레스트 (Breiman, 2001)**: 다수의 의사결정나무를 결합한 앙상블 방법
- **그래디언트 부스팅**: 의사결정나무를 기반 학습기로 사용하는 부스팅 앙상블

본 논문은 기계학습 분야에서 가장 많이 인용되는 논문 중 하나로, 의사결정나무 기반 알고리즘의 이론적 출발점이다.
