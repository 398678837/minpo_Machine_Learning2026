# 논문 4 상세 번역/해설: Top-Down Induction of Decision Trees Classifiers - A Survey

> **원제**: Top-Down Induction of Decision Trees Classifiers - A Survey
> **저자**: Lior Rokach, Oded Maimon (2005)
> **학술지**: IEEE Transactions on Systems, Man, and Cybernetics - Part C

---

## 1. 서론: 의사결정나무의 분류 체계

### 1.1 TDIDT의 정의

TDIDT(Top-Down Induction of Decision Trees)는 루트 노드에서 시작하여 재귀적으로 데이터를 분할해 나가는 의사결정나무 구축 방법의 총칭이다. ID3, C4.5, CART, CHAID 등 대부분의 의사결정나무 알고리즘이 이 범주에 속한다.

### 1.2 일반적 TDIDT 알고리즘

```
함수 BuildTree(D, Attributes):
    1. 노드 N을 생성한다.
    2. 정지 기준(Stopping Criteria)을 확인한다.
       - 모든 샘플이 같은 클래스이면 -> 리프 노드 반환
       - 속성이 없으면 -> 다수 클래스의 리프 노드 반환
       - 최소 샘플 수 미달이면 -> 리프 노드 반환
    3. 분할 기준(Splitting Criteria)에 따라 최적 속성 A*와 분할 조건 s*를 선택한다.
    4. A*의 각 분할 결과 v에 대해:
       - D_v = {d in D | d가 분할 조건 s*에서 값 v에 해당}
       - 자식 노드 = BuildTree(D_v, Attributes)
    5. N을 반환한다.
```

## 2. 분할 기준 (Splitting Criteria) 상세 분석

### 2.1 불순도 기반 기준 (Impurity-Based Criteria)

불순도 함수 phi(p1, p2, ..., pc)는 다음 조건을 만족해야 한다:
- phi는 p에 대해 오목(concave)하다.
- phi는 (1/c, 1/c, ..., 1/c)에서 최대값을 가진다.
- phi는 단위 벡터 (1, 0, ..., 0), ..., (0, 0, ..., 1)에서 최소값 0을 가진다.

#### (a) 엔트로피 (Entropy / Information Gain)

```
H(t) = -SUM_{i=1}^{c} p(i|t) * log2(p(i|t))
```

- 정보 이론에 기반한다.
- ID3에서 처음 사용, C4.5에서 정보 이득 비율로 발전하였다.
- 로그 연산이 필요하여 계산 비용이 지니보다 높다.

#### (b) 지니 불순도 (Gini Impurity)

```
Gini(t) = 1 - SUM_{i=1}^{c} p(i|t)^2
          = SUM_{i != j} p(i|t) * p(j|t)
```

- CART에서 사용한다.
- "임의로 선택한 두 샘플이 다른 클래스일 확률"로 해석한다.
- scikit-learn의 기본값이다.

#### (c) 분류 오류 (Classification Error)

```
Error(t) = 1 - max_i p(i|t)
```

- 가장 단순하지만, 미분 불가능한 지점이 있어 분할 기준으로는 덜 선호된다.
- 가지치기에서 오류율 추정에 사용한다.

### 2.2 세 기준의 비교 (이진 분류)

```
p = 클래스 1의 비율

Entropy:   -p*log2(p) - (1-p)*log2(1-p)   범위: [0, 1.0]
Gini:      2p(1-p)                          범위: [0, 0.5]
Error:     1 - max(p, 1-p)                  범위: [0, 0.5]

세 기준 모두 p = 0.5에서 최대, p = 0 또는 1에서 0
엔트로피와 지니는 엄격히 오목(strictly concave), 오류는 부분적 선형
```

### 2.3 거리 기반 기준 (Distance-Based Criteria)

#### 카이제곱 검정 (Chi-Square Test)

CHAID(Chi-squared Automatic Interaction Detector) 알고리즘에서 사용하며, 분할의 통계적 유의성을 검정한다:

```
Chi^2 = SUM_{i,j} (O_{ij} - E_{ij})^2 / E_{ij}
```

여기서 O는 관측 빈도, E는 기대 빈도이다. p-value가 유의수준 이하일 때만 분할을 수행한다.

장점: 통계적으로 유의미한 분할만 수행하여 자동으로 트리 복잡도를 제어한다.
단점: 유의수준 설정에 민감하며, 불순도 기반 기준보다 보수적일 수 있다.

### 2.4 다변량 분할 (Multivariate Split)

단일 속성이 아닌 여러 속성의 선형 조합으로 분할 기준을 정의한다:

```
a1*X1 + a2*X2 + ... + am*Xm <= c
```

대표 알고리즘:
- **CART-LC (Linear Combination)**: CART의 확장으로 선형 조합 분할을 허용
- **OC1 (Oblique Classifier 1)**: 경사 분할을 위한 최적화 알고리즘

장점: 축 정렬 분할로는 표현하기 어려운 대각선 결정 경계를 효율적으로 표현한다.
단점: 해석이 어렵고, 최적 계수를 찾는 것이 NP-hard 문제이다.

## 3. 정지 기준 (Stopping Criteria)

### 3.1 일반적 정지 기준

| 기준 | 설명 | scikit-learn 파라미터 |
|:---|:---|:---|
| 최대 깊이 도달 | 트리 깊이가 설정값에 도달 | `max_depth` |
| 최소 분할 샘플 수 | 노드의 샘플 수가 최소값 미만 | `min_samples_split` |
| 최소 리프 샘플 수 | 분할 후 자식 노드의 샘플 수가 최소값 미만이면 분할 불가 | `min_samples_leaf` |
| 순수 노드 | 노드의 모든 샘플이 동일 클래스 | (자동) |
| 속성 소진 | 사용 가능한 속성이 없음 | (자동) |
| 정보 이득 임계값 | 정보 이득이 최소값 미만 | `min_impurity_decrease` |

### 3.2 사전 가지치기 vs 사후 가지치기

**사전 가지치기 (Pre-Pruning, Early Stopping)**:
- 트리 성장 중에 정지 기준으로 성장을 중단한다.
- 장점: 계산 효율적(불필요한 노드를 생성하지 않음).
- 단점: "지평선 효과(horizon effect)" - 현재 분할의 정보 이득이 낮더라도, 후속 분할에서 큰 이득이 발생할 수 있다. 조기 중단으로 이를 놓칠 수 있다.

**사후 가지치기 (Post-Pruning)**:
- 트리를 완전히 성장시킨 후, 불필요한 가지를 제거한다.
- 장점: 지평선 효과를 피할 수 있다.
- 단점: 완전한 트리를 먼저 생성해야 하므로 계산 비용이 높다.

## 4. 가지치기 방법의 상세 비교

### 4.1 비용-복잡도 가지치기 (CCP, CART)

```
R_alpha(T) = R(T) + alpha * |T_leaf|
```

- alpha를 0에서 무한대로 변화시키며 최적 하위 트리 시퀀스를 생성한다.
- 교차검증으로 최적 alpha를 선택한다.
- 이론적으로 가장 엄밀하며, scikit-learn의 `ccp_alpha`로 구현되어 있다.

### 4.2 오류 기반 가지치기 (EBP, C4.5)

- 비관적 오류 추정에 기반한다.
- 별도의 검증 데이터가 필요하지 않다.
- 가지 올리기(subtree raising)를 지원한다.

### 4.3 최소 오류 가지치기 (MEP)

- Niblett & Bratko (1986)가 제안하였다.
- 각 노드에서 하위 트리와 리프의 예상 오류를 비교하여 가지치기한다.
- 라플라스 추정(Laplace estimate)으로 오류율을 보정한다.

### 4.4 MDL 기반 가지치기 (Minimum Description Length)

- 최소 설명 길이(MDL) 원리에 기반한다.
- 모델(트리)의 설명 길이 + 데이터의 설명 길이를 최소화한다.
- 정보 이론적으로 가장 우아하지만, 구현이 복잡하다.

## 5. 결측값 처리 방법의 비교

| 방법 | 알고리즘 | 설명 |
|:---|:---|:---|
| 대리 분할 (Surrogate) | CART | 유사한 분할을 수행하는 대체 속성 사용 |
| 분수적 분배 (Fractional) | C4.5 | 값 분포에 비례하여 각 분기에 분배 |
| 결측 분기 (Separate) | 일부 알고리즘 | 결측값을 별도의 분기로 처리 |
| 대체 (Imputation) | 전처리 | 평균/중앙값/최빈값 등으로 대체 후 학습 |

## 6. 실험적 비교 결과

### 6.1 분할 기준 비교

Rokach와 Maimon은 다수의 실험 연구를 종합하여 다음과 같은 결론을 내린다:

- 엔트로피와 지니 불순도는 대부분의 데이터셋에서 **통계적으로 유의한 차이가 없다**.
- 카디널리티가 높은 속성이 있을 때는 정보 이득 비율(C4.5)이 정보 이득(ID3)보다 우수하다.
- 카이제곱 기반 기준(CHAID)은 통계적 유의성을 보장하지만, 보수적이어서 중요한 분할을 놓칠 수 있다.

### 6.2 가지치기 방법 비교

- 사후 가지치기가 사전 가지치기보다 일반적으로 우수하다.
- CCP(CART)와 EBP(C4.5)는 대부분의 데이터셋에서 유사한 성능을 보인다.
- 가지치기 없는 트리는 거의 항상 과적합되며, 어떤 형태의 가지치기든 적용하는 것이 바람직하다.

## 7. 고급 주제

### 7.1 비용 민감 학습 (Cost-Sensitive Learning)

현실에서는 오분류 비용이 클래스마다 다르다. 예를 들어, 의료 진단에서 암 환자를 정상으로 판정하는 오류(위음성)는 정상인을 암으로 판정하는 오류(위양성)보다 비용이 훨씬 크다.

비용 민감 트리에서는 불순도 측도를 비용 행렬로 가중한다:

```
Cost-Weighted Gini(t) = SUM_{i != j} C(i,j) * p(i|t) * p(j|t)
```

여기서 C(i,j)는 클래스 i를 클래스 j로 오분류하는 비용이다.

### 7.2 불균형 데이터 처리

클래스 불균형(class imbalance)이 심한 경우, 의사결정나무는 다수 클래스에 편향된 분할을 수행할 수 있다. 이를 해결하기 위한 방법:

- **비용 민감 학습**: 소수 클래스의 오분류 비용을 높게 설정
- **재표본 추출**: 소수 클래스 오버샘플링 또는 다수 클래스 언더샘플링
- **class_weight 조정**: scikit-learn의 `class_weight='balanced'` 옵션

### 7.3 대규모 데이터 처리

데이터가 메모리에 적재되지 않을 정도로 클 때의 확장 가능한(scalable) 의사결정나무 알고리즘:

- **SPRINT**: 디스크 기반 분할 알고리즘
- **SLIQ**: 정렬된 리스트 기반의 빠른 분할
- **RainForest**: 메모리 적응형 프레임워크

## 8. 요약 및 연구 방향

본 서베이의 핵심 메시지:

1. **설계 선택의 중요성**: 의사결정나무의 성능은 분할 기준, 가지치기 방법, 결측값 처리 등의 설계 선택에 크게 의존한다.
2. **보편적 최적 방법은 없다**: No Free Lunch 정리에 따라, 모든 데이터셋에서 최적인 단일 방법은 존재하지 않는다.
3. **앙상블의 우월성**: 단일 트리의 한계(높은 분산, 불안정성)는 앙상블 기법(랜덤 포레스트, 부스팅)으로 효과적으로 극복할 수 있다.
4. **해석 가능성의 가치**: 앙상블 방법이 더 높은 성능을 제공하지만, 단일 트리의 해석 가능성은 여전히 중요한 가치를 가진다.
