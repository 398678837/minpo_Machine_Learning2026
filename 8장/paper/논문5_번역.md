## 1. 서론: 트리 모델의 역사

### 1.1 의사결정나무의 기원

Loh는 의사결정나무의 역사를 1960년대까지 거슬러 올라간다. 최초의 트리 기반 알고리즘은 Morgan과 Sonquist(1963)의 **AID(Automatic Interaction Detection)**로, 사회과학 연구에서 변수 간 교호작용을 탐지하기 위해 개발되었다. AID는 F-검정을 사용하여 분할 변수를 선택하며, 현대 의사결정나무의 원형이라 할 수 있다.

### 1.2 주요 발전 경로

```
연대기적 발전:

1963  AID (Morgan & Sonquist)     - 최초의 트리 알고리즘
1973  THAID (Messenger & Mandell) - AID의 분류 버전
1980  CHAID (Kass)                - 카이제곱 기반 분할
1984  CART (Breiman et al.)       - 지니 불순도, CCP
1986  ID3 (Quinlan)               - 정보 이득
1993  C4.5 (Quinlan)              - 정보 이득 비율
1997  QUEST (Loh & Shih)          - 편향 없는 분할
2002  CRUISE (Kim & Loh)          - 다변량 분할
2009  GUIDE (Loh)                 - 편향 없는 + 교호작용
```

## 2. 변수 선택 편향 문제

### 2.1 편향의 정의

**변수 선택 편향(variable selection bias)**이란, 트리 알고리즘이 특정 유형의 변수를 분할 변수로 불공정하게 선호하는 현상이다. 이 편향이 존재하면:

1. **잘못된 변수 중요도**: 실제로 중요하지 않은 변수가 높은 중요도를 가지는 것으로 평가된다.
2. **비최적 분할**: 더 유용한 변수를 놔두고 편향된 변수로 분할하여 성능이 저하된다.
3. **해석의 왜곡**: 변수 간의 진정한 관계가 왜곡되어 잘못된 인사이트를 도출할 수 있다.

### 2.2 CART의 변수 선택 편향

CART의 지니 불순도(또는 엔트로피) 기반 분할은 **카디널리티가 높은 변수를 선호**하는 편향이 있다.

**이유**: 카디널리티가 높은 변수는 더 많은 후보 분할점을 가지므로, 순전히 우연으로 높은 지니 감소를 달성할 확률이 높다. 이는 "다중 비교(multiple comparison)" 문제의 일종이다.

**실험적 증거**: 10개의 독립적이고 무관한 변수가 있을 때, CART는 카디널리티가 높은 변수를 루트 노드에서 선택하는 비율이 이론적 기대값(10%)보다 훨씬 높다.

```
실험 예시 (모든 변수가 타겟과 무관할 때):

변수 유형          | 카디널리티 | CART 선택 비율 | 기대 비율
2값 범주형         |     2      |     5%        |   10%
4값 범주형         |     4      |     8%        |   10%
10값 범주형        |    10      |    15%        |   10%
연속형 (100 고유값) |   100      |    32%        |   10%

-> 카디널리티가 높을수록 선택 비율이 불균형적으로 높다
```

### 2.3 C4.5의 변수 선택 편향

C4.5의 정보 이득 비율은 카디널리티 편향을 완화하지만 완전히 제거하지는 못한다. 또한, **결측값 비율이 높은 변수**에 대한 새로운 편향이 발생할 수 있다.

### 2.4 편향 없는 알고리즘: 통계적 검정 기반

Loh는 편향 없는 변수 선택을 위해 **통계적 가설 검정(statistical hypothesis testing)**을 사용하는 방법을 소개한다:

1. 각 후보 변수에 대해, 타겟 변수와의 연관성을 검정한다.
2. 검정 통계량을 p-value로 변환한다.
3. **p-value가 가장 작은 변수**를 분할 변수로 선택한다.

핵심: 검정 통계량이 변수 유형(범주형/연속형)과 카디널리티에 대해 적절히 보정되므로, 편향이 제거된다.

대표적 알고리즘:
- **QUEST** (Quick, Unbiased, Efficient Statistical Tree): 각 변수에 대해 F-검정 또는 카이제곱 검정을 수행하여 분할 변수를 선택한다.
- **CRUISE**: QUEST를 확장하여 다변량 분할을 지원한다.
- **GUIDE**: 잔차 패턴 분석으로 교호작용까지 검출한다.

## 3. 트리 알고리즘의 분류 체계

### 3.1 Loh의 분류 체계

Loh는 트리 알고리즘을 두 가지 축으로 분류한다:

**(1) 분할 변수 선택 방법**
- **불순도 기반 (Impurity-based)**: CART, C4.5 - 편향 있음
- **검정 기반 (Test-based)**: CHAID, QUEST, GUIDE - 편향 없음(또는 감소)

**(2) 분할점 결정 방법**
- **탐욕적 탐색 (Exhaustive search)**: 모든 후보 분할점을 평가
- **선형 판별 분석 (LDA-based)**: 분할점을 LDA로 결정
- **이산화 후 탐색**: 연속형 변수를 먼저 이산화한 후 탐색

### 3.2 주요 알고리즘 비교

| 알고리즘 | 변수 선택 | 분할점 결정 | 변수 선택 편향 | 분할 유형 |
|:---|:---|:---|:---|:---|
| CART | 지니 불순도 | 탐욕적 탐색 | 있음 (카디널리티) | 단변량 이진 |
| C4.5 | 정보 이득 비율 | 탐욕적 탐색 | 있음 (감소됨) | 단변량 다중 |
| CHAID | 카이제곱 검정 | 카이제곱 | 감소됨 | 단변량 다중 |
| QUEST | F-검정/카이제곱 | LDA | 없음 | 단변량/다변량 이진 |
| CRUISE | 카이제곱 | LDA | 없음 | 단변량/다변량 이진 |
| GUIDE | 잔차 패턴 검정 | LDA/탐욕적 | 없음 | 단변량/다변량 이진 |

## 4. 모델 트리 (Model Tree)

### 4.1 전통적 회귀 트리의 한계

전통적 회귀 트리(CART)는 각 리프 노드에서 **상수(평균)**를 예측값으로 사용한다. 이는 구간별 상수 함수(piecewise constant function)로, 다음과 같은 한계가 있다:

1. **불연속적 예측**: 리프 경계에서 예측값이 급격히 변한다.
2. **비효율적 표현**: 선형 관계를 포착하려면 매우 많은 리프가 필요하다.
3. **외삽 불가**: 학습 범위 밖의 입력에 대해 적절한 예측을 할 수 없다.

### 4.2 모델 트리의 개념

모델 트리는 각 리프 노드에서 상수 대신 **선형 회귀 모델**을 적합한다:

```
전통적 회귀 트리:
  리프 1: y_hat = 3.5 (상수)
  리프 2: y_hat = 7.2 (상수)
  리프 3: y_hat = 1.8 (상수)

모델 트리:
  리프 1: y_hat = 2.1 + 0.5*X1 - 0.3*X2 (선형 회귀)
  리프 2: y_hat = 5.0 + 1.2*X1           (선형 회귀)
  리프 3: y_hat = 0.8 - 0.1*X1 + 0.7*X3  (선형 회귀)
```

이렇게 하면 각 영역 내에서 선형 관계를 포착할 수 있어, 더 적은 리프로도 정확한 예측이 가능하다.

### 4.3 대표적 모델 트리 알고리즘

- **M5** (Quinlan, 1992): 각 리프에서 다중 선형 회귀를 적합
- **M5'** (Wang & Witten, 1997): M5의 개선 버전
- **GUIDE** (Loh, 2002): 편향 없는 변수 선택 + 리프 모델

## 5. 실험적 비교 결과

### 5.1 분류 문제에서의 비교

Loh는 32개의 UCI 데이터셋에서 13개 트리 알고리즘을 비교하였다. 주요 발견:

1. **단일 트리 중에서는 GUIDE가 가장 안정적**이다 (편향 없는 변수 선택 덕분).
2. **CART와 C4.5는 대부분의 데이터셋에서 유사한 성능**을 보인다.
3. **가지치기의 영향이 분할 기준의 영향보다 크다** - 어떤 불순도 측도를 사용하든, 적절한 가지치기가 있으면 성능이 유사하다.
4. **앙상블 방법(랜덤 포레스트 등)은 모든 단일 트리보다 우수**하다.

### 5.2 회귀 문제에서의 비교

1. **모델 트리가 구간별 상수 트리보다 일반적으로 우수**하다.
2. **GUIDE의 모델 트리가 가장 좋은 성능**을 보였다.
3. **트리 크기(리프 수)와 예측 정확도 사이의 최적점**이 존재한다.

## 6. 현대적 확장과 응용

### 6.1 앙상블과의 관계

Loh는 단일 트리의 한계(높은 분산, 불안정성)를 인정하면서, 앙상블 방법이 이를 효과적으로 해결한다고 논의한다:

- **랜덤 포레스트**: 배깅 + 특성 랜덤 선택으로 분산을 줄인다.
- **그래디언트 부스팅**: 순차적 트리로 편향을 줄인다.
- **앙상블에서도 편향 없는 기본 트리 사용이 유리**할 수 있다.

### 6.2 생존 분석 트리

의료 연구에서의 생존 분석(survival analysis)에 트리를 적용하는 방법:
- 생존 시간과 중도절단(censoring) 데이터를 처리
- 로그 순위 검정(log-rank test)을 분할 기준으로 사용
- Kaplan-Meier 생존 곡선을 각 리프에서 추정

### 6.3 종방향 데이터 트리

반복 측정(longitudinal) 데이터에 대한 트리:
- 개인 내 상관(within-subject correlation)을 고려
- 혼합 효과 모델(mixed-effects model)을 리프에서 적합
- RE-EM 트리(Random Effects/Expectation Maximization Tree)

## 7. 핵심 요약

### 본 논문의 핵심 메시지

1. **변수 선택 편향은 트리 알고리즘의 근본적 문제**이며, 이를 인식하고 해결하는 것이 중요하다.
2. **분할 변수 선택과 분할점 결정의 분리**가 편향 제거의 핵심 원리이다.
3. **가지치기가 분할 기준보다 더 중요**한 설계 선택이다.
4. **모델 트리**는 전통적 회귀 트리보다 표현력이 뛰어나다.
5. **앙상블 방법**은 단일 트리의 한계를 극복하는 가장 효과적인 방법이다.

### 실무적 시사점

- scikit-learn의 `feature_importances_`는 CART의 편향된 변수 중요도이므로, 순열 중요도(permutation importance)와 교차 검증하는 것이 바람직하다.
- 데이터에 카디널리티가 다양한 변수가 혼재할 때, CART 기반 트리의 결과를 무비판적으로 수용하지 말아야 한다.
- 회귀 문제에서는 모델 트리(예: M5)가 더 적합한 선택일 수 있다.
