> **저자**: J. Ross Quinlan (1993)

## 1. C4.5의 탄생 배경

### 1.1 ID3의 한계

Quinlan은 1986년에 발표한 ID3 알고리즘의 여러 한계를 인식하고, 이를 체계적으로 해결한 C4.5를 개발하였다. ID3의 주요 한계는 다음과 같다:

1. **카디널리티 편향**: 정보 이득 기준이 값의 종류가 많은 속성을 부당하게 선호한다.
2. **연속형 속성 미지원**: 기본 ID3는 범주형 속성만 처리할 수 있다.
3. **가지치기 부재**: 체계적인 가지치기 방법이 없어 과적합에 취약하다.
4. **결측값 미지원**: 결측값이 있는 데이터를 처리할 수 없다.
5. **다중 분기의 비효율성**: 범주 수가 많은 속성에서 지나치게 많은 분기가 생성된다.

### 1.2 C4.5의 설계 목표

- ID3의 모든 한계를 해결하면서도 알고리즘의 단순성과 효율성을 유지한다.
- 실세계 데이터의 복잡성(노이즈, 결측값, 비용 등)을 반영한다.
- 생성된 분류기의 해석 가능성을 보존한다.

## 2. 정보 이득 비율 (Gain Ratio)

### 2.1 카디널리티 편향 문제의 구체적 예시

10명의 환자 데이터에서 "환자 ID"라는 속성을 생각해보자. 각 환자 ID는 고유하므로, ID로 분할하면 각 리프에 정확히 1명의 환자만 존재하여 엔트로피가 0이 된다. 따라서 정보 이득은 최대값이 된다:

```
IG(S, ID) = H(S) - SUM(1/10 * 0) = H(S)

-> 정보 이득이 최대이지만, ID로 분류하는 것은 전혀 일반화되지 않는다!
```

### 2.2 분할 정보 (Split Information)

이 문제를 해결하기 위해, Quinlan은 속성 A 자체의 "내재적 정보량"인 **분할 정보(Split Information)**를 도입한다:

```
SplitInfo(S, A) = -SUM_{v in Values(A)} (|S_v| / |S|) * log2(|S_v| / |S|)
```

분할 정보는 속성 A의 값 분포에 대한 엔트로피이다. 카디널리티가 높을수록(값의 종류가 많을수록) 분할 정보가 커진다.

위의 예시에서:
```
SplitInfo(S, ID) = -10 * (1/10) * log2(1/10) = log2(10) ≈ 3.32
```

### 2.3 정보 이득 비율

정보 이득 비율은 정보 이득을 분할 정보로 나눈 값이다:

```
GainRatio(S, A) = IG(S, A) / SplitInfo(S, A)
```

이렇게 하면 카디널리티가 높은 속성의 정보 이득이 큰 분할 정보로 나누어져 상대적으로 작아진다.

### 2.4 실용적 주의사항

정보 이득 비율은 분할 정보가 매우 작은 경우(거의 모든 데이터가 하나의 값에 집중된 경우) 비정상적으로 큰 값을 가질 수 있다. Quinlan은 이를 방지하기 위해 다음과 같은 휴리스틱을 적용한다:

- 정보 이득이 평균 이상인 속성들만 후보로 고려한다.
- 그 중에서 정보 이득 비율이 최대인 속성을 선택한다.

## 3. 연속형 속성의 처리

### 3.1 이진 분할점 탐색

연속형 속성 A에 대해, C4.5는 다음 절차로 최적 분할점을 찾는다:

1. 훈련 데이터를 속성 A의 값 기준으로 정렬한다.
2. 인접한 두 값의 중간점(midpoint)을 후보 분할점으로 설정한다. 단, 클래스가 다른 인접 쌍만 고려하면 효율적이다.
3. 각 후보 분할점 c에 대해, "A <= c" vs "A > c"로 분할한 후의 정보 이득(또는 정보 이득 비율)을 계산한다.
4. 정보 이득이 최대인 분할점을 선택한다.

```
예시: 속성값과 클래스
  A:     1.5  2.3  3.1  4.7  5.2  6.8
  Class:  +    +    -    -    +    -

후보 분할점: 2.7, 3.9, 4.95, 6.0
(클래스가 변경되는 경계에서만 후보 설정)

각 분할점에서 정보 이득 계산 후 최대값 선택
```

### 3.2 분할점에 대한 보정

연속형 속성의 경우, 분할점 자체가 하나의 추가적인 자유도(degree of freedom)를 가지므로, 정보 이득이 약간 과대평가될 수 있다. C4.5는 이에 대한 보정항을 적용한다:

```
보정된 IG(S, A, c) = IG(S, A, c) - log2(N-1) / |S|
```

여기서 N은 속성 A의 서로 다른 값의 수이다.

## 4. 오류 기반 가지치기 (Error-Based Pruning)

### 4.1 비관적 오류 추정

C4.5의 가지치기는 **비관적 오류 추정(pessimistic error estimate)**에 기반한다. 노드 t에서 N개의 샘플 중 E개가 오분류되었다면:

- 관찰된 오류율: e = E / N
- 비관적 오류율: 이항 분포의 상한 신뢰구간 (기본 신뢰수준: 25%)

```
비관적 오류 수 = N * UCF(E, N, CF)
```

여기서 UCF는 신뢰수준 CF에서의 이항 분포 상한을 계산하는 함수이다.

### 4.2 가지치기 규칙

내부 노드 t에 대해, 다음 세 가지 옵션 중 비관적 오류가 가장 작은 것을 선택한다:

1. **가지치기 안 함**: t 아래의 하위 트리를 그대로 유지한다. 비관적 오류는 각 리프의 비관적 오류의 가중 합이다.
2. **리프로 대체**: t를 가장 빈번한 클래스의 리프 노드로 대체한다. 비관적 오류는 t에서의 비관적 오류이다.
3. **가지 올리기(subtree raising)**: t의 가장 빈번한 하위 트리를 t의 위치로 올린다.

### 4.3 CART CCP와의 비교

| 측면 | C4.5 EBP | CART CCP |
|:---|:---|:---|
| 검증 데이터 | 불필요 (비관적 추정 사용) | 필요 (교차검증) |
| 파라미터 | 신뢰 수준 (CF) | 복잡도 파라미터 (alpha) |
| 접근 방식 | 상향식 (bottom-up) | 하향식 (top-down) |
| 이론적 기반 | 이항 분포 신뢰구간 | 최적화 이론 |
| 가지 올리기 | 지원 | 미지원 |

## 5. 결측값 처리

### 5.1 학습 시 결측값 처리

C4.5는 결측값을 가진 인스턴스를 **분수적으로 분배(fractional distribution)**한다:

1. 속성 A에 결측값이 없는 인스턴스들로만 정보 이득을 계산한다.
2. 결측값을 가진 인스턴스는 속성 A의 값 분포에 비례하여 각 분기에 분수적 가중치로 분배한다.

```
예시: 10개 인스턴스, 속성 A의 값 분포
  A=red: 6개, A=blue: 2개, A 결측: 2개

  -> 결측 인스턴스의 가중치 분배:
     red 분기: 2 * 6/8 = 1.5
     blue 분기: 2 * 2/8 = 0.5
```

### 5.2 예측 시 결측값 처리

새로운 인스턴스를 분류할 때 분할 속성의 값이 결측이면, 해당 인스턴스를 각 분기에 확률적으로 분배하여 각 리프에서의 클래스 확률을 조합한다.

## 6. 규칙 집합으로의 변환

### 6.1 트리에서 규칙으로

의사결정나무의 각 루트-리프 경로는 하나의 if-then 규칙으로 변환할 수 있다:

```
트리:
  [A <= 3.0]
   ├── [B = "yes"] -> 클래스 1
   └── [B = "no"]  -> 클래스 0

규칙 1: IF A <= 3.0 AND B = "yes" THEN 클래스 1
규칙 2: IF A <= 3.0 AND B = "no"  THEN 클래스 0
```

### 6.2 규칙 단순화

각 규칙에서 조건을 하나씩 제거하면서 정확도가 저하되지 않는 조건을 식별하여 제거한다. 이렇게 하면 트리 형태보다 더 간결한 규칙 집합을 얻을 수 있다.

### 6.3 규칙 집합의 장점

- **독립적 최적화**: 각 규칙을 독립적으로 단순화할 수 있어, 트리 가지치기보다 세밀한 최적화가 가능하다.
- **중복 제거**: 불필요한 조건을 제거하여 더 간결한 분류기를 생성한다.
- **해석 용이성**: 트리보다 규칙 집합이 인간에게 더 자연스러운 표현일 수 있다.

## 7. C4.5의 역사적 위치

### 7.1 "데이터 마이닝 10대 알고리즘" 1위

2006년 IEEE ICDM(International Conference on Data Mining)에서 실시한 투표에서, C4.5는 SVM, AdaBoost, KNN, Naive Bayes 등을 제치고 **데이터 마이닝 분야 10대 알고리즘 1위**로 선정되었다. 이는 C4.5의 실용성, 이론적 완성도, 영향력을 보여주는 결과이다.

### 7.2 후속 발전

- **C5.0/See5**: C4.5의 상업적 후속 버전. 부스팅 지원, 메모리 효율 향상.
- **CART와의 수렴**: 현대 구현(scikit-learn 등)에서는 C4.5와 CART의 아이디어가 통합되어 사용된다.
- **앙상블 기법의 기초**: 랜덤 포레스트, 그래디언트 부스팅 등은 C4.5/CART 스타일의 의사결정나무를 기본 학습기로 사용한다.

### 7.3 현대적 관점에서의 C4.5

C4.5 자체는 현재 단독으로 사용되는 경우가 줄었지만, C4.5에서 도입된 핵심 개념들(정보 이득 비율, 오류 기반 가지치기, 연속형 속성 처리, 결측값의 확률적 처리)은 현대 기계학습 시스템의 기반으로 남아 있다. 특히, 모델 해석성(interpretability)이 중요시되는 의료, 금융, 법률 분야에서 의사결정나무(및 규칙 추출)는 여전히 핵심 도구이다.
