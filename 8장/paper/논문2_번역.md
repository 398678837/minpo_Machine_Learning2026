## 1. 서론: CART의 철학

### 1.1 통계학적 관점의 의사결정나무

CART의 저자들은 통계학자로서, 의사결정나무를 **비모수적 분류 및 회귀 방법(nonparametric classification and regression method)**으로 정립하였다. 이는 Quinlan의 컴퓨터 과학적 접근(기계학습/인공지능)과 대비되는 관점이다.

핵심 원칙:
- **구조적 단순성**: 트리 구조는 인간이 이해하기 쉬운 if-then 규칙의 집합으로 표현된다.
- **통계적 엄밀성**: 오분류율의 추정, 트리 복잡도 선택 등에 교차검증 등 통계적 방법을 적용한다.
- **범용성**: 분류와 회귀를 동일한 프레임워크에서 처리한다.

### 1.2 CART vs ID3의 근본적 차이

| 측면 | CART (Breiman et al.) | ID3 (Quinlan) |
|:---|:---|:---|
| 학문적 배경 | 통계학 | 컴퓨터 과학/AI |
| 분할 방식 | 항상 이진 분할 | 다중 분할 허용 |
| 분할 기준 | 지니 불순도 | 정보 이득(엔트로피) |
| 가지치기 | 비용-복잡도 가지치기 (체계적) | 규칙 기반 가지치기 (휴리스틱) |
| 회귀 지원 | 지원 (MSE 기준) | 미지원 (분류만) |
| 결측값 처리 | 대리 분할 (surrogate split) | 분수적 분배 또는 무시 |

## 2. 이진 분할 (Binary Splitting)

### 2.1 이진 분할의 원리

CART에서 모든 분할은 데이터를 정확히 두 부분집합으로 나눈다:
- **수치형 속성**: "X_j <= c" 형태의 분할 (c는 임계값)
- **범주형 속성**: "X_j in S" 형태의 분할 (S는 범주의 부분집합)

예를 들어, "색상"이라는 범주형 속성의 값이 {빨강, 파랑, 초록}이라면:
- 분할 1: {빨강} vs {파랑, 초록}
- 분할 2: {파랑} vs {빨강, 초록}
- 분할 3: {초록} vs {빨강, 파랑}

3개의 후보 분할 중 지니 불순도 감소가 가장 큰 분할을 선택한다.

### 2.2 이진 분할의 장점

1. **일관된 트리 구조**: 모든 노드가 정확히 두 자식을 가지므로 분석이 용이하다.
2. **데이터 세분화 방지**: 다중 분할은 한 번에 데이터를 많은 부분으로 나누어 각 부분의 표본 크기가 작아지지만, 이진 분할은 단계적으로 데이터를 나눈다.
3. **연속형/범주형 통합 처리**: 모든 속성 유형에 대해 동일한 이진 분할 프레임워크를 적용한다.

## 3. 지니 불순도 (Gini Impurity)

### 3.1 정의와 계산

노드 t에서의 지니 불순도는 다음과 같이 정의된다:

```
Gini(t) = 1 - SUM_{i=1}^{c} p(i|t)^2
```

여기서 p(i|t)는 노드 t에서 클래스 i의 비율이다.

### 3.2 지니 불순도의 직관적 의미

지니 불순도는 **"노드에서 무작위로 두 샘플을 뽑았을 때, 서로 다른 클래스에 속할 확률"**로 해석할 수 있다.

이진 분류에서의 지니 불순도:
```
p = 클래스 1의 비율

Gini = 1 - p^2 - (1-p)^2 = 2p(1-p)

p=0.0 -> Gini = 0.00 (완전 순수: 모두 클래스 0)
p=0.1 -> Gini = 0.18
p=0.3 -> Gini = 0.42
p=0.5 -> Gini = 0.50 (최대 불순: 50:50)
p=0.7 -> Gini = 0.42
p=1.0 -> Gini = 0.00 (완전 순수: 모두 클래스 1)
```

### 3.3 지니 vs 엔트로피 비교

Breiman 등은 지니 불순도와 엔트로피가 실무적으로 거의 동일한 분할을 생성한다고 보고하였다. 두 기준의 주요 차이는:

- **계산 효율성**: 지니 불순도는 로그 연산이 없어 계산이 빠르다.
- **이론적 배경**: 엔트로피는 정보 이론, 지니는 확률 이론에 기반한다.
- **곡선 형태**: 이진 분류에서 지니는 포물선(2p(1-p)), 엔트로피는 오목 곡선(-p*log(p)-(1-p)*log(1-p))이다.

## 4. 비용-복잡도 가지치기 (Cost-Complexity Pruning)

### 4.1 동기: 과적합 문제

완전히 성장한 트리 T_max는 훈련 데이터를 완벽하게 분류할 수 있지만, 새로운 데이터에 대한 일반화 성능은 떨어진다. 이는 트리가 훈련 데이터의 노이즈까지 학습하기 때문이다. 따라서, **적절한 복잡도의 트리**를 선택하는 것이 핵심 과제이다.

### 4.2 비용-복잡도 함수

트리 T에 대한 비용-복잡도 측도(cost-complexity measure)는 다음과 같이 정의된다:

```
R_alpha(T) = R(T) + alpha * |T_leaf|
```

여기서:
- R(T): 트리 T의 오분류 비용 (또는 MSE)
- |T_leaf|: 트리 T의 리프 노드 수 (복잡도)
- alpha: 복잡도 페널티 파라미터 (alpha >= 0)

alpha가 0이면 가지치기가 수행되지 않고(가장 복잡한 트리), alpha가 증가할수록 더 적극적인 가지치기가 수행된다(더 단순한 트리).

### 4.3 최적 하위 트리 선택 절차

1. **완전 트리 성장**: 가지치기 없이 트리를 완전히 성장시켜 T_max를 생성한다.

2. **하위 트리 열거**: alpha를 0에서 무한대로 증가시키면서, 각 alpha에서 비용-복잡도가 최소인 하위 트리 T(alpha)를 계산한다. 이때, alpha가 증가하는 과정에서 유한 개의 서로 다른 최적 하위 트리 시퀀스가 생성된다:

```
T_max = T_1 ⊃ T_2 ⊃ ... ⊃ T_k = {루트 노드}
```

3. **각 내부 노드에 대한 유효 alpha 계산**: 내부 노드 t에 대해, 해당 노드 아래의 하위 트리를 리프로 대체했을 때의 alpha 값:

```
alpha_eff(t) = (R(t) - R(T_t)) / (|T_t_leaf| - 1)
```

여기서 R(t)는 노드 t를 리프로 만들었을 때의 오분류 비용, R(T_t)는 노드 t 아래 하위 트리의 오분류 비용, |T_t_leaf|는 하위 트리의 리프 수이다.

4. **가지치기 순서**: alpha_eff가 가장 작은 내부 노드부터 순서대로 가지치기한다. alpha_eff가 작다는 것은 "복잡도 대비 성능 기여가 작다"는 의미이므로, 가장 비효율적인 분할부터 제거된다.

5. **교차검증으로 최적 alpha 선택**: 5-폴드 또는 10-폴드 교차검증을 수행하여, 검증 오류가 최소인 alpha (또는 1-SE rule에 의한 alpha)를 선택한다.

### 4.4 1-SE Rule

교차검증에서 최적 alpha를 선택할 때, Breiman은 **1-SE(Standard Error) Rule**을 권장하였다:
- 교차검증 오류가 최소인 alpha를 alpha_min이라 하자.
- alpha_min에서의 교차검증 오류의 표준오차를 SE라 하자.
- 최종 alpha는 교차검증 오류가 (최소 오류 + 1*SE) 이하인 범위에서 **가장 큰 alpha**를 선택한다.

이 규칙은 "통계적으로 유의하지 않은 성능 차이 범위 내에서 가장 단순한 모델"을 선택하는 오컴의 면도날(Occam's Razor) 원리를 반영한다.

## 5. 대리 분할 (Surrogate Split)

### 5.1 개념

최적 분할 속성 X_j에 대해, 어떤 샘플에서 X_j의 값이 결측된 경우, 해당 분할과 가장 유사한 결과를 내는 다른 속성 X_k의 분할을 **대리 분할(surrogate split)**로 사용한다.

### 5.2 대리 분할의 선택

속성 X_k의 분할 s_k가 최적 분할 s*와 얼마나 유사한지는, 두 분할이 동일한 결과를 내는 비율(예측 일치도, predictive association)로 측정된다:

```
예측 일치도 = (s_k와 s*가 동일한 분기로 보내는 샘플 수) / (전체 샘플 수)
```

예측 일치도가 가장 높은 속성의 분할을 1순위 대리 분할로 사용하고, 그 다음 높은 것을 2순위로 사용한다.

## 6. 회귀 트리 (Regression Tree)

### 6.1 분할 기준: MSE 감소

회귀 문제에서 CART는 분할 기준으로 MSE(Mean Squared Error) 감소를 사용한다:

```
MSE(t) = (1/N_t) * SUM_{i in t} (y_i - y_bar_t)^2

MSE 감소 = MSE(부모) - [N_left/N * MSE(왼쪽) + N_right/N * MSE(오른쪽)]
```

각 리프 노드의 예측값은 해당 노드에 속하는 샘플들의 평균값이다.

### 6.2 회귀 트리의 특징

- **구간별 상수 함수(piecewise constant function)**: 각 리프 노드 영역 내에서 예측값이 상수이므로, 입력 공간을 직사각형 영역으로 분할하고 각 영역에서 상수값을 예측하는 것과 동일하다.
- **비연속적 예측**: 영역 경계에서 예측값이 불연속적으로 변한다.
- **외삽 불가**: 훈련 데이터 범위를 벗어나는 입력에 대해서는 경계 영역의 평균값을 반환하므로, 외삽(extrapolation)이 불가능하다.

## 7. 변수 중요도 (Variable Importance)

### 7.1 불순도 기반 중요도

CART에서 변수 X_j의 중요도는 트리의 모든 노드에서 X_j를 사용한 분할의 불순도 감소량의 합으로 정의된다:

```
VarImp(X_j) = SUM_{t: split on X_j} N_t/N * (Gini감소_t)
```

이 값은 모든 변수의 중요도 합이 1이 되도록 정규화된다.

### 7.2 대리 분할 기반 중요도

주 분할 변수뿐만 아니라, 대리 분할에서 사용된 변수의 기여도도 포함하여 변수 중요도를 계산할 수 있다. 이는 변수 간의 상관관계를 고려한 보다 로버스트한 중요도 측정을 가능하게 한다.

## 8. 핵심 요약

### CART의 영향

CART는 현대 기계학습에서 의사결정나무의 표준 구현이 되었으며, 그 영향은 다음과 같다:

1. **scikit-learn의 구현**: `DecisionTreeClassifier`와 `DecisionTreeRegressor`는 CART 알고리즘을 기반으로 한다.
2. **앙상블 기법의 기초**: 랜덤 포레스트, 그래디언트 부스팅 등 현대 앙상블 방법은 CART를 기반 학습기로 사용한다.
3. **비용-복잡도 가지치기의 표준화**: CCP는 사후 가지치기의 표준 방법으로 널리 채택되었다.
4. **변수 중요도의 개념**: 트리 기반 모델에서 변수 중요도를 계산하는 방법의 원형을 제시하였다.

### 현대적 의의

CART에서 제안된 이진 분할, 지니 불순도, CCP, 변수 중요도 등의 개념은 30년이 지난 현재에도 기계학습의 핵심 도구로 사용되고 있으며, XGBoost, LightGBM 등 최신 알고리즘의 기술적 기반이 되고 있다.
