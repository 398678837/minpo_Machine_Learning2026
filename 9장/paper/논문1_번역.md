# 논문 1 상세 번역/해설: Random Forests

> **원제**: Random Forests
> **저자**: Leo Breiman (2001)
> **학술지**: Machine Learning, Vol. 45, No. 1, pp. 5-32

---

## 1. 서론: 앙상블 학습의 배경

### 1.1 배깅에서 랜덤 포레스트로

Breiman은 1996년에 배깅(Bagging: Bootstrap Aggregating)을 제안한 바 있다. 배깅은 부트스트랩 샘플로 학습한 여러 모델의 예측을 결합하여 분산을 줄이는 방법이다. 그러나 배깅만으로는 트리 간의 상관관계가 충분히 감소하지 않는다는 한계가 있었다.

랜덤 포레스트는 배깅에 **랜덤 특성 선택(random feature selection)**을 추가하여 트리 간의 상관관계를 더욱 줄인다. 핵심 아이디어는 각 노드의 분할 시 전체 p개의 특성 중 m개만 랜덤으로 선택하고, 그 중에서 최적 분할을 찾는 것이다.

### 1.2 랜덤 포레스트의 정의

Breiman은 랜덤 포레스트를 다음과 같이 형식적으로 정의한다:

> **정의**: 랜덤 포레스트는 트리 구조의 분류기(또는 회귀기)의 집합 {h(x, Theta_k), k=1,...,K}이다. 여기서 {Theta_k}는 독립적이고 동일한 분포를 따르는 랜덤 벡터이며, 각 트리는 입력 x에 대해 가장 빈번한 클래스(분류) 또는 평균(회귀)으로 투표한다.

## 2. 이론적 분석

### 2.1 일반화 오류의 상계

랜덤 포레스트의 핵심 이론적 결과는 일반화 오류에 대한 상계(upper bound)이다.

**마진 함수(Margin Function)**:
```
mg(X, Y) = av_k I(h_k(X) = Y) - max_{j != Y} av_k I(h_k(X) = j)
```

마진은 "올바른 클래스에 대한 평균 투표 비율 - 가장 높은 다른 클래스에 대한 평균 투표 비율"이다. 마진이 양수이면 정확한 분류, 음수이면 오분류이다.

**일반화 오류**:
```
PE* = P_{X,Y}(mg(X, Y) < 0)
```

**Breiman의 핵심 부등식**:
```
PE* <= rho_bar * (1 - s^2) / s^2
```

여기서:
- rho_bar: 트리 간 상관관계의 평균
- s: 개별 트리의 강도(정확도)

### 2.2 부등식의 의미

이 부등식은 랜덤 포레스트 설계의 두 가지 핵심 원리를 제시한다:

1. **트리 간 상관관계(rho_bar)를 줄여야 한다**: 트리 간 상관관계가 낮을수록 일반화 오류의 상계가 감소한다. 이것이 랜덤 특성 선택의 이론적 근거이다.

2. **개별 트리의 강도(s)를 높여야 한다**: 각 트리가 더 정확할수록 일반화 오류가 감소한다.

그러나 이 두 목표는 트레이드오프 관계에 있다. 랜덤 특성 선택에서 m(선택할 특성 수)을 줄이면 상관관계는 감소하지만 개별 트리의 강도도 감소한다. 반대로 m을 늘리면 강도는 증가하지만 상관관계도 증가한다.

**최적의 m 선택**: 이 트레이드오프에서 최적점을 찾는 것이 `max_features` 하이퍼파라미터 튜닝의 본질이다.

### 2.3 과적합에 대한 강건성

Breiman은 대수의 법칙(Strong Law of Large Numbers)을 적용하여, 트리 수 K가 증가할 때 랜덤 포레스트의 일반화 오류가 특정 값으로 수렴함을 증명한다:

```
PE* -> P_{X,Y}(P_Theta(h(X, Theta) = Y) - max_{j != Y} P_Theta(h(X, Theta) = j) < 0)
```

이는 **트리를 아무리 많이 추가해도 과적합이 발생하지 않는다**는 것을 의미한다. 이는 부스팅(boosting)과의 핵심적 차이점으로, 부스팅은 반복 횟수가 과도하면 과적합될 수 있다.

## 3. Out-of-Bag (OOB) 오류 추정

### 3.1 OOB의 원리

부트스트랩 샘플링에서 각 트리의 학습에 사용되지 않는 샘플의 비율은 약 36.8%이다 (정확히 1 - (1-1/n)^n -> 1-1/e ≈ 0.632, 즉 약 63.2%가 사용되고 36.8%가 사용되지 않음).

OOB 추정 절차:
1. 각 훈련 샘플 (x_i, y_i)에 대해, x_i가 OOB인 트리들(x_i를 학습에 사용하지 않은 트리들)만 모은다.
2. 이 트리들의 투표로 x_i의 예측 클래스를 결정한다.
3. 모든 훈련 샘플에 대해 위 과정을 반복하여 OOB 오류율을 계산한다.

```
OOB 오류 추정 = (OOB 예측이 틀린 샘플 수) / (전체 훈련 샘플 수)
```

### 3.2 OOB의 장점

- **교차검증 불필요**: OOB 추정은 별도의 검증 세트나 교차검증 없이 일반화 오류를 추정한다.
- **편향 없는 추정**: Breiman은 OOB 추정이 K-fold 교차검증과 유사한 정확도를 가짐을 실험적으로 보였다.
- **계산 효율**: 모델 학습과 동시에 오류 추정이 가능하므로 추가적인 계산 비용이 적다.

## 4. 변수 중요도 (Variable Importance)

### 4.1 불순도 감소 기반 중요도 (MDI)

각 변수의 중요도를 해당 변수로 분할할 때의 불순도(지니 또는 엔트로피) 감소량의 합으로 측정한다:

```
MDI(X_j) = (1/K) * SUM_{k=1}^{K} SUM_{t: split on X_j in tree k} N_t/N * Delta_impurity(t)
```

장점: 계산이 빠르다 (트리 학습 과정에서 자동으로 계산).
단점: 카디널리티가 높은 변수나 연속형 변수에 편향될 수 있다.

### 4.2 순열 기반 중요도 (MDA, Permutation Importance)

OOB 샘플에서 각 변수의 값을 무작위로 섞은(permute) 후 정확도 감소를 측정한다:

```
MDA(X_j) = (1/K) * SUM_{k=1}^{K} [OOB_accuracy_k - OOB_accuracy_k(X_j permuted)]
```

절차:
1. 각 트리 k에 대해, OOB 샘플의 정확도를 계산한다.
2. OOB 샘플에서 변수 X_j의 값을 무작위로 섞는다.
3. 섞은 데이터로 정확도를 다시 계산한다.
4. 정확도 감소량이 변수 X_j의 중요도이다.

**직관**: 변수 X_j가 중요하다면, 그 값을 섞으면 예측 정확도가 크게 떨어진다. 반면, 중요하지 않은 변수를 섞어도 정확도에 거의 영향이 없다.

장점: MDI보다 편향이 적다.
단점: 계산 비용이 높다 (각 변수마다 별도의 예측 수행 필요).

## 5. 실험 결과

### 5.1 분류 문제에서의 성능

Breiman은 다양한 벤치마크 데이터셋에서 랜덤 포레스트와 다른 알고리즘을 비교하였다:

| 알고리즘 | 평균 오류율 순위 |
|:---|:---|
| 랜덤 포레스트 | 1-2위 |
| AdaBoost | 2-3위 |
| 배깅 | 3-4위 |
| 단일 CART | 5-6위 |

랜덤 포레스트는 대부분의 데이터셋에서 AdaBoost와 유사하거나 우수한 성능을 보였으며, 배깅보다는 일관되게 우수하였다.

### 5.2 max_features (m) 의 영향

Breiman은 m의 선택에 대해 다음과 같은 권장사항을 제시하였다:

- **분류**: m = floor(sqrt(p)) (p는 전체 특성 수)
- **회귀**: m = floor(p/3)
- OOB 오류를 기준으로 m을 튜닝하는 것이 가장 좋다.

m이 너무 작으면(예: m=1) 각 트리가 매우 약해져서 앙상블 성능이 저하된다. m이 너무 크면(예: m=p) 일반 배깅과 동일해져서 트리 간 상관관계 감소 효과가 사라진다.

## 6. 근접도 (Proximity)

### 6.1 근접도 행렬

랜덤 포레스트는 데이터 포인트 간의 **근접도(proximity)**를 자연스럽게 제공한다:

두 데이터 포인트 i와 j가 같은 리프 노드에 도달하는 트리의 비율을 근접도로 정의한다:

```
prox(i, j) = (i와 j가 같은 리프에 떨어지는 트리 수) / (전체 트리 수)
```

### 6.2 근접도의 활용

- **결측값 대체**: 근접도가 높은 샘플의 값으로 결측값을 가중 평균하여 대체
- **이상치 탐지**: 모든 다른 샘플과의 근접도가 낮은 샘플을 이상치로 식별
- **데이터 시각화**: 근접도 행렬을 다차원 스케일링(MDS)으로 2D에 투영

## 7. 핵심 요약

### 랜덤 포레스트가 강력한 이유

1. **이중 랜덤성**: 부트스트랩(데이터 랜덤) + 특성 선택(특성 랜덤)으로 트리 간 다양성을 극대화
2. **과적합 강건성**: 트리 수를 늘려도 과적합이 발생하지 않음 (대수의 법칙)
3. **내장 검증**: OOB 추정으로 별도의 검증 없이 일반화 오류 추정
4. **변수 중요도**: MDI와 MDA로 변수의 예측 기여도를 정량화
5. **최소 튜닝**: max_features만 조정하면 대부분의 경우 좋은 성능을 얻을 수 있음

### 한계

1. **해석의 어려움**: 수백 개의 트리를 결합한 모델은 단일 트리처럼 직관적으로 해석하기 어렵다.
2. **계산 비용**: 트리 수가 많을수록 학습과 예측에 시간이 걸린다.
3. **외삽 불가**: 학습 데이터 범위를 벗어나는 예측이 어렵다 (특히 회귀).
4. **편향된 변수 중요도**: MDI는 카디널리티에 편향될 수 있다.
