## 1. 서론: randomForest 패키지

### 1.1 구현 배경

Liaw와 Wiener는 Breiman과 Cutler가 개발한 랜덤 포레스트의 원본 Fortran 코드를 R 언어에서 사용할 수 있도록 인터페이싱한 `randomForest` 패키지를 소개한다. 이 패키지는 빠르게 랜덤 포레스트의 표준 구현이 되었으며, 이후 Python의 scikit-learn 등 다른 언어의 구현에도 영향을 미쳤다.

### 1.2 기본 사용법

```r
# R 코드 예시 (개념 이해용)
library(randomForest)

# 분류
rf_clf <- randomForest(Species ~ ., data=iris, ntree=500, mtry=2)
print(rf_clf)

# 회귀
rf_reg <- randomForest(medv ~ ., data=Boston, ntree=500, mtry=4)
print(rf_reg)
```

Python(scikit-learn) 대응:
```python
# Python 코드 대응
from sklearn.ensemble import RandomForestClassifier, RandomForestRegressor

# 분류
rf_clf = RandomForestClassifier(n_estimators=500, max_features=2)

# 회귀
rf_reg = RandomForestRegressor(n_estimators=500, max_features=4)
```

## 2. 핵심 파라미터 상세 설명

### 2.1 ntree (n_estimators)

트리의 수를 결정한다. 더 많은 트리는 더 안정적인 예측을 제공하지만, 특정 수를 넘으면 성능 향상이 미미해진다.

**권장사항**:
- 기본값 500을 시작점으로 사용한다.
- OOB 오류의 수렴을 확인하여 충분한지 판단한다.
- 계산 시간이 허용하는 범위에서 큰 값을 사용하는 것이 안전하다.

```
ntree에 따른 OOB 오류 수렴:

ntree    OOB 오류
  50     0.0533
 100     0.0467
 200     0.0433
 500     0.0400
1000     0.0400  <- 수렴
2000     0.0400
```

### 2.2 mtry (max_features)

각 노드 분할 시 후보로 고려할 특성의 수이다. 랜덤 포레스트에서 가장 중요한 하이퍼파라미터이다.

**기본값**:
- 분류: floor(sqrt(p)) (p는 전체 특성 수)
- 회귀: floor(p/3)

**mtry의 효과**:
- mtry가 작을수록: 트리 간 상관관계 감소, 개별 트리 약화
- mtry가 클수록: 트리 간 상관관계 증가, 개별 트리 강화
- mtry = p: 일반 배깅과 동일

**튜닝 방법**: OOB 오류를 기준으로 여러 mtry 값을 시험한다.

```r
# R에서의 mtry 튜닝 (개념)
tuneRF(x=iris[,-5], y=iris[,5], stepFactor=1.5)
```

Python 대응:
```python
# Python에서의 max_features 튜닝
for m in [2, 3, 4, 5, 'sqrt', 'log2']:
    rf = RandomForestClassifier(max_features=m, oob_score=True)
    rf.fit(X_train, y_train)
    print(f"max_features={m}: OOB score={rf.oob_score_:.4f}")
```

### 2.3 nodesize (min_samples_leaf)

리프 노드의 최소 샘플 수를 설정한다.

**기본값**:
- 분류: 1 (트리를 완전히 성장시킴)
- 회귀: 5

값이 클수록 트리가 단순해지고 학습 속도가 빨라진다.

## 3. OOB 오류 추정의 실용적 활용

### 3.1 OOB 오류 계산 과정

1. 랜덤 포레스트의 각 트리 k에 대해, 부트스트랩에 포함되지 않은 OOB 샘플을 식별한다.
2. 각 훈련 샘플 i에 대해, i가 OOB인 트리들만 모아 투표로 예측한다.
3. OOB 예측과 실제 레이블을 비교하여 오류율을 계산한다.

```
예시: 5개 트리, 6개 훈련 샘플

      트리1  트리2  트리3  트리4  트리5
샘플1   B      -     B      B      -     -> OOB 트리: {2,5}, OOB 예측: ?
샘플2   -      A     -      A      A     -> OOB 트리: {1,3}, OOB 예측: ?
...

B = 부트스트랩에 포함 (학습에 사용)
- = OOB (학습에 사용되지 않음)
```

### 3.2 OOB vs 교차검증

Liaw와 Wiener는 OOB 오류가 leave-one-out 교차검증(LOOCV)과 매우 유사한 결과를 제공한다고 보고한다. 이는 각 샘플이 약 K/3개의 트리에서 OOB로 사용되므로, 충분한 수의 트리에서 검증되기 때문이다.

장점:
- **추가 비용 없음**: 모델 학습 과정에서 자동으로 계산된다.
- **별도의 검증 세트 불필요**: 훈련 데이터만으로 일반화 성능을 추정한다.
- **하이퍼파라미터 튜닝 기준**: 교차검증 대신 OOB 오류로 mtry를 튜닝한다.

## 4. 변수 중요도의 실용적 해석

### 4.1 Mean Decrease Accuracy (MDA)

순열 중요도(Permutation Importance)의 구체적 계산 과정:

```
각 트리 k에 대해:
  1. OOB 샘플로 정확도를 계산한다: acc_k
  2. 변수 X_j의 OOB 값을 무작위로 섞는다.
  3. 섞은 데이터로 정확도를 다시 계산한다: acc_k_permuted
  4. 변수 X_j의 중요도 기여: acc_k - acc_k_permuted

MDA(X_j) = (1/K) * SUM_k (acc_k - acc_k_permuted)
```

### 4.2 Mean Decrease Gini (MDG / MDI)

각 변수가 트리의 모든 노드에서 지니 불순도를 얼마나 감소시키는지의 합:

```
MDG(X_j) = (1/K) * SUM_k SUM_{t in tree_k, split on X_j} Delta_Gini(t)
```

### 4.3 MDA vs MDG 비교

| 측면 | MDA (순열) | MDG (지니) |
|:---|:---|:---|
| 편향 | 적음 | 카디널리티에 편향 |
| 계산 비용 | 높음 | 낮음 (자동 계산) |
| 이론적 근거 | 직관적 (정확도 감소) | 불순도 감소 합 |
| scikit-learn | `permutation_importance()` | `feature_importances_` |

## 5. 부분 의존도 그림 (Partial Dependence Plot)

### 5.1 개념

부분 의존도(Partial Dependence)는 하나 또는 두 개의 특성이 예측에 미치는 한계 효과(marginal effect)를 시각화한다.

변수 X_s에 대한 부분 의존도 함수:
```
f_hat_s(X_s) = (1/N) * SUM_{i=1}^{N} f_hat(X_s, x_{i,C})
```

여기서 x_{i,C}는 나머지 변수들의 관측값이다.

**직관**: 관심 변수 X_s의 값을 고정하고, 나머지 변수들은 훈련 데이터의 실제 값을 사용하여 평균 예측을 구한다. 이를 X_s의 여러 값에 대해 반복하면 X_s와 예측 사이의 관계를 시각화할 수 있다.

### 5.2 Python에서의 구현

```python
from sklearn.inspection import PartialDependenceDisplay

# 부분 의존도 그림 생성
PartialDependenceDisplay.from_estimator(
    rf_model, X_train,
    features=[0, 1, (0, 1)],  # 개별 + 상호작용
    kind='average'
)
```

## 6. 근접도(Proximity)의 실용적 활용

### 6.1 결측값 대체

1. 먼저 결측값을 중앙값(수치형) 또는 최빈값(범주형)으로 초기화한다.
2. 랜덤 포레스트를 학습하고 근접도 행렬을 계산한다.
3. 각 결측값을 근접도로 가중한 비결측 값의 가중 평균으로 대체한다.
4. 2-3을 수렴할 때까지 반복한다.

```
결측값 대체 공식:
x_hat_ij = SUM_k prox(i,k) * x_kj / SUM_k prox(i,k)
(k는 변수 j가 결측이 아닌 샘플)
```

### 6.2 이상치 탐지

이상치 측도(outlier measure)를 다음과 같이 정의한다:

```
outlier(i) = N / SUM_{j: class(j) = class(i)} prox(i,j)^2
```

같은 클래스의 다른 샘플들과의 근접도가 낮으면(즉, 어떤 트리에서도 같은 리프에 잘 떨어지지 않으면) 이상치 측도가 높아진다.

## 7. 불균형 데이터 처리

### 7.1 문제 정의

클래스 불균형이 심한 경우(예: 사기 탐지에서 사기 0.1%, 정상 99.9%), 랜덤 포레스트는 다수 클래스로 편향된 예측을 할 수 있다.

### 7.2 해결 방법

1. **비용 민감 학습**: 소수 클래스의 오분류 비용을 높게 설정한다.
   - scikit-learn: `class_weight='balanced'`

2. **층화 부트스트랩 샘플링**: 각 부트스트랩 샘플에서 클래스 비율을 동일하게 유지한다.

3. **다운샘플링**: 각 트리 학습 시 다수 클래스를 소수 클래스 크기로 다운샘플링한다.

본 논문의 실용적 가이드라인:

1. **ntree**: 500부터 시작, OOB 수렴 확인
2. **mtry**: 기본값(sqrt(p) 또는 p/3)을 시작으로 OOB 기준 튜닝
3. **nodesize**: 분류는 1, 회귀는 5를 기본으로 사용
4. **변수 중요도**: MDA(순열)와 MDG(지니) 모두 확인
5. **OOB 오류**: 교차검증 대신 활용 가능
6. **부분 의존도**: 변수의 한계 효과를 시각적으로 해석
