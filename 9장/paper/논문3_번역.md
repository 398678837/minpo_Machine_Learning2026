## 1. 서론: 왜 변수 중요도 편향이 문제인가?

### 1.1 변수 중요도의 중요성

랜덤 포레스트는 높은 예측 성능뿐만 아니라 **변수 중요도(variable importance)**를 자동으로 제공한다는 점에서 많은 연구자에게 매력적인 도구이다. 특히 생물정보학에서는:

- **유전체 연구**: 수천 개의 유전자 중 질병과 관련된 핵심 유전자를 식별
- **SNP 분석**: 수백만 개의 SNP 중 표현형과 연관된 변이를 찾기
- **바이오마커 발견**: 진단이나 예후에 유용한 바이오마커 선별

이러한 응용에서 변수 중요도가 편향되면, 실제로는 중요하지 않은 변수를 핵심 변수로 잘못 식별하거나, 진정으로 중요한 변수를 놓칠 수 있다.

### 1.2 두 가지 변수 중요도 방법

**지니 중요도 (Gini Importance, MDI)**:
```
MDI(X_j) = (1/K) * SUM_k SUM_{t in tree_k, split on X_j} p(t) * Delta_Gini(t)
```

**순열 중요도 (Permutation Importance, MDA)**:
```
MDA(X_j) = (1/K) * SUM_k [accuracy_k^OOB - accuracy_k^OOB(X_j permuted)]
```

## 2. 지니 중요도의 편향

### 2.1 카디널리티 편향의 원인

지니 중요도가 카디널리티가 높은 변수를 선호하는 근본 원인은 **다중 검정(multiple testing) 효과**이다.

연속형 변수는 N-1개의 후보 분할점을 가지는 반면, 2값 범주형 변수는 1개의 후보 분할점만 가진다. 후보가 많을수록 순전히 우연으로 높은 지니 감소를 달성할 확률이 높아진다.

### 2.2 시뮬레이션 실험

Strobl 등은 다음과 같은 시뮬레이션으로 편향을 증명한다:

**설정**: 타겟 변수 Y와 완전히 독립인 12개의 변수를 생성한다. 변수들은 카디널리티가 다르다:
- X1, X2: 2개 범주
- X3, X4: 4개 범주
- X5, X6: 10개 범주
- X7, X8: 20개 범주
- X9, X10: 연속형 (균일 분포)
- X11, X12: 연속형 (정규 분포)

**결과**: 모든 변수가 타겟과 무관함에도 불구하고:
- **지니 중요도**: 연속형 변수 > 고카디널리티 범주형 > 저카디널리티 범주형 순서로 "중요하다"고 평가된다.
- **순열 중요도**: 모든 변수의 중요도가 0 근처로, 편향이 없다.

```
변수      | 카디널리티 | 지니 중요도 | 순열 중요도
X1 (2범주)  |     2      |   0.005    |   0.000
X3 (4범주)  |     4      |   0.010    |   0.001
X5 (10범주) |    10      |   0.025    |   0.000
X7 (20범주) |    20      |   0.045    |   0.001
X9 (연속)   |   ~100     |   0.080    |  -0.001
X11 (연속)  |   ~100     |   0.078    |   0.000

-> 지니 중요도: 카디널리티가 높을수록 편향적으로 높음
-> 순열 중요도: 모두 0 근처 (편향 없음)
```

## 3. 순열 중요도의 편향

### 3.1 상관된 변수에서의 문제

순열 중요도는 카디널리티 편향은 없지만, **상관된 변수가 있을 때** 편향이 발생한다.

**시나리오**: X1과 X2가 높은 상관관계(rho=0.9)를 가지며, X1이 타겟 Y와 관련이 있고 X2는 X1을 통해서만 간접적으로 Y와 연관된다.

순열 중요도에서 X1을 섞으면:
- X2가 여전히 X1의 대리(proxy) 역할을 하므로, 정확도 감소가 예상보다 작다.
- 결과: X1의 중요도가 **과소평가**된다.

X2를 섞으면:
- X1이 여전히 예측에 기여하므로, 정확도 감소가 적다.
- 하지만 X2가 실제로 타겟과 직접 관련이 없어도, 상관 구조 때문에 0이 아닌 중요도를 가질 수 있다.

### 3.2 주변부 vs 조건부 독립

**주변부 독립(Marginal Independence)**: X_j를 무조건적으로 섞는다. 이는 X_j와 Y 사이의 주변부 관계를 측정한다.

**조건부 독립(Conditional Independence)**: X_j를 다른 변수 X_C에 조건부로 섞는다. 이는 X_C를 통제한 후 X_j가 Y에 추가적으로 기여하는 정보를 측정한다.

기존의 순열 중요도는 주변부 독립을 측정하므로, 상관 변수의 영향이 혼입(confounding)된다.

## 4. 해결책: 조건부 순열 중요도

### 4.1 알고리즘

조건부 순열 중요도의 핵심 아이디어는, X_j를 섞을 때 다른 변수들의 값에 **조건부로** 섞는 것이다:

```
절차:
1. 조건부 변수 Z를 선택한다 (X_j와 상관된 변수들).
2. Z의 값에 따라 데이터를 그룹(bin)으로 나눈다.
   - 연속형 Z: 분위수(quantile)로 그룹화
   - 범주형 Z: 범주별 그룹화
3. 각 그룹 내에서만 X_j의 값을 무작위로 섞는다.
4. 섞은 데이터로 정확도를 계산한다.
5. 정확도 감소를 조건부 순열 중요도로 사용한다.
```

### 4.2 직관적 이해

**기존 순열**: X_j를 전체 데이터에서 무작위로 섞으면, X_j와 다른 변수들 사이의 상관 구조가 파괴된다. 이로 인해 비현실적인 데이터 조합이 생성된다.

**조건부 순열**: 같은 그룹 내에서만 섞으므로, X_j와 다른 변수들 사이의 상관 구조가 대략적으로 보존된다. 따라서, X_j가 다른 변수들을 통제한 후에도 Y에 추가 정보를 제공하는지를 더 정확하게 측정한다.

### 4.3 실험 결과

```
시나리오: X1(타겟 관련) + X2(X1과 상관 rho=0.9, 타겟과 직접 무관)

                    X1 중요도  X2 중요도
기존 순열 중요도:     0.05       0.03    (X2가 허위로 높음)
조건부 순열 중요도:   0.08       0.00    (X2가 정확히 0)
```

## 5. 조건부 추론 포레스트 (Conditional Inference Forest)

### 5.1 기본 아이디어

CART 트리를 기반 학습기로 사용하는 대신, **조건부 추론 트리(conditional inference tree, ctree)**를 사용한다. ctree는 다음 두 단계로 분할을 수행한다:

1. **변수 선택**: 각 변수에 대해 타겟과의 연관성을 순열 검정(permutation test)으로 평가한다. p-value가 가장 작은 변수를 선택한다.
2. **분할점 결정**: 선택된 변수에 대해 최적 분할점을 찾는다.

### 5.2 편향 제거의 원리

순열 검정의 핵심 특성: **검정의 p-value는 변수의 유형과 카디널리티에 대해 자동으로 보정된다.** 따라서 모든 변수가 타겟과 무관할 때, 어떤 변수든 선택될 확률이 동일하다 (카디널리티 편향 없음).

## 6. 실무적 권장사항

### 6.1 변수 중요도 해석 가이드라인

1. **지니 중요도(MDI)만 사용하지 말 것**: 특히 변수의 유형이나 카디널리티가 다양한 경우, 지니 중요도는 편향된 결과를 줄 수 있다.

2. **순열 중요도(MDA)를 우선 사용할 것**: 카디널리티 편향은 없지만, 상관된 변수가 있으면 주의가 필요하다.

3. **상관된 변수가 있을 때는 조건부 순열 중요도를 사용할 것**: 변수 간 상관 구조가 복잡한 경우(예: 유전체 데이터) 조건부 방법이 더 정확하다.

4. **두 가지 이상의 중요도 방법을 비교할 것**: 방법 간 결과가 일치하면 해석의 신뢰도가 높아진다.

### 6.2 Python에서의 구현

```python
# scikit-learn에서의 순열 중요도
from sklearn.inspection import permutation_importance

# 순열 중요도 계산
perm_imp = permutation_importance(
    rf_model, X_test, y_test,
    n_repeats=30,           # 반복 횟수
    random_state=42,
    n_jobs=-1
)

# 결과 확인
for i in perm_imp.importances_mean.argsort()[::-1]:
    print(f"{feature_names[i]}: "
          f"{perm_imp.importances_mean[i]:.4f} "
          f"+/- {perm_imp.importances_std[i]:.4f}")
```
