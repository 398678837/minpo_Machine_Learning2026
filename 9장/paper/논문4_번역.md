## 1. 서론: 예측 불확실성의 필요성

### 1.1 점 예측의 한계

랜덤 포레스트의 표준 출력은 **점 예측(point prediction)**이다:
- 분류: "이 환자는 양성(benign)이다"
- 회귀: "이 집의 가격은 3억 원이다"

그러나 실무에서는 점 예측만으로는 충분하지 않다:
- "이 예측은 얼마나 **확실**한가?"
- "예측의 **오차 범위**는 얼마인가?"
- "이 변수가 **통계적으로 유의미하게** 기여하는가?"

이러한 질문에 답하려면 예측에 대한 **불확실성(uncertainty)**을 정량화해야 한다.

### 1.2 기존 접근의 한계

기존의 불확실성 추정 방법들의 한계:
- **트리 간 분산**: 각 트리의 예측 분산을 계산할 수 있지만, 이는 앙상블 예측의 분산과 다르다.
- **부트스트랩 신뢰구간**: 랜덤 포레스트 자체가 부트스트랩 기반이므로, 단순히 트리 예측의 분산으로 신뢰구간을 구성하면 과소추정될 수 있다.
- **교차검증**: 오류율은 추정하지만 개별 예측의 불확실성은 제공하지 않는다.

## 2. 이론적 기초: 서브배깅과 점근 정규성

### 2.1 랜덤 포레스트의 U-통계량 해석

Mentch와 Hooker의 핵심 통찰은 랜덤 포레스트를 **불완전 U-통계량(incomplete U-statistic)**으로 해석하는 것이다.

**U-통계량**: n개의 데이터에서 크기 k의 모든 부분집합에 대해 함수를 적용하고 평균한 것.
- 모든 C(n,k) 부분집합을 사용하면 **완전 U-통계량**
- 일부 B개의 부분집합만 사용하면 **불완전 U-통계량**

랜덤 포레스트는 B개의 (서브)부트스트랩 샘플에 트리를 학습하고 평균하므로, 불완전 U-통계량으로 볼 수 있다.

### 2.2 서브배깅 (Subbagging)

표준 부트스트랩(복원추출, 크기 n)은 이론적 분석이 어렵다. 저자들은 **서브배깅(subsample bagging)**으로 분석을 단순화한다:

- 크기 k의 부분집합을 **비복원추출**로 추출 (k << n)
- 각 부분집합으로 트리를 학습
- B개 트리의 예측을 평균

이 설정에서 Hoeffding의 U-통계량 이론을 적용할 수 있다.

### 2.3 점근 정규성 정리

**정리 (비형식적 서술)**:
k/n -> 0이고 B -> 무한대일 때, 새로운 데이터 x에 대한 서브배깅 예측 f_hat(x)는 다음과 같이 점근적으로 정규 분포를 따른다:

```
sqrt(n) * (f_hat(x) - E[f_hat(x)]) -> N(0, sigma^2(x))
```

여기서 sigma^2(x)는 예측의 조건부 분산이다.

이 결과는 **충분히 많은 트리**와 **적절한 서브샘플 크기**가 있을 때, 랜덤 포레스트 예측의 분포를 정규 분포로 근사할 수 있음을 보장한다.

## 3. 분산 추정: 무한소 잭나이프 (IJ)

### 3.1 IJ 분산 추정량의 개념

무한소 잭나이프(Infinitesimal Jackknife)는 각 훈련 샘플 i가 앙상블 예측에 미치는 **한계 영향(marginal influence)**을 계산하여 분산을 추정한다.

**핵심 아이디어**: 훈련 샘플 i의 가중치를 미세하게 변화시켰을 때, 예측이 얼마나 변하는지를 측정한다.

### 3.2 구체적 계산 방법

새로운 데이터 x에 대한 IJ 분산 추정:

```
V_hat_IJ(x) = SUM_{i=1}^{n} cov_hat_i(x)^2
```

여기서:
```
cov_hat_i(x) = (1/B) * SUM_{b=1}^{B} (N_{bi} - N_bar_i) * (T_b(x) - T_bar(x))
```

- N_{bi}: 트리 b의 부트스트랩 샘플에서 관측값 i의 출현 횟수
- N_bar_i: N_{bi}의 평균
- T_b(x): 트리 b의 x에 대한 예측
- T_bar(x): 전체 앙상블의 예측 (모든 트리의 평균)

### 3.3 직관적 이해

cov_hat_i(x)는 **"관측값 i가 더 많이 사용될수록 예측이 어떻게 변하는가?"**를 측정한다.

- 관측값 i가 자주 포함된 트리(N_{bi}가 큰 트리)들의 예측이 높고, 적게 포함된 트리들의 예측이 낮다면 -> cov_hat_i가 양수 -> 관측값 i가 예측을 높이는 방향으로 영향
- 이러한 영향의 합이 전체 분산을 구성한다.

### 3.4 편향 보정

IJ 분산 추정량은 Monte Carlo 분산(유한한 트리 수에 의한 분산)을 포함하므로, 이를 보정해야 한다:

```
V_hat_IJ_corrected(x) = V_hat_IJ(x) - V_hat_MC(x)

V_hat_MC(x) = (1/B) * SUM_b (T_b(x) - T_bar(x))^2 / B
```

## 4. 신뢰구간 구성

### 4.1 점별 신뢰구간

새로운 데이터 x에 대한 (1-alpha) 신뢰구간:

```
f_hat(x) +/- z_{alpha/2} * sqrt(V_hat_IJ_corrected(x))
```

여기서 z_{alpha/2}는 표준 정규 분포의 상위 alpha/2 분위수이다.

**예시** (95% 신뢰구간):
```
예측값: 3.5 (단위: $100,000)
IJ 표준오차: 0.3
95% 신뢰구간: 3.5 +/- 1.96 * 0.3 = [2.91, 4.09]

해석: "이 집의 가격은 $291,000 ~ $409,000 사이일 가능성이 95%이다"
```

### 4.2 예측 구간 (Prediction Interval)

신뢰구간은 **기대 예측의 불확실성**을 나타내지만, **실제 관측값의 변동성**까지 포함하려면 예측 구간이 필요하다:

```
예측 구간 = f_hat(x) +/- z_{alpha/2} * sqrt(V_hat_IJ(x) + sigma_hat^2)
```

여기서 sigma_hat^2은 잔차 분산의 추정값이다.

## 5. 가설 검정

### 5.1 변수 중요도 검정

변수 X_j가 예측에 유의미하게 기여하는지를 검정한다.

**영가설**: H_0: E[f_hat(x)] = E[f_hat_{-j}(x)]
(변수 X_j를 제외한 모델의 예측과 차이가 없다)

**검정 통계량**:
```
T = (f_hat(x) - f_hat_{-j}(x)) / sqrt(V_hat_diff(x))
```

T가 점근적으로 N(0,1)을 따르므로, 표준 정규 분포 기반 검정을 수행한다.

### 5.2 모델 비교 검정

두 랜덤 포레스트 모델 f1과 f2의 예측이 통계적으로 다른지를 검정한다.

## 6. 보정 분석 (Calibration Analysis)

### 6.1 보정의 개념

95% 신뢰구간을 구성했다면, **실제로 참값의 약 95%가 구간에 포함**되어야 한다. 이를 **보정(calibration)**이라 한다.

- **과소 커버리지 (Undercoverage)**: 실제 커버리지가 명목보다 낮다. 신뢰구간이 너무 좁다.
- **과대 커버리지 (Overcoverage)**: 실제 커버리지가 명목보다 높다. 신뢰구간이 너무 넓다.
- **적절한 보정**: 실제 커버리지가 명목에 가깝다.

### 6.2 보정 실험 결과

Mentch와 Hooker는 다양한 데이터셋에서 IJ 신뢰구간의 커버리지를 평가하였다:

```
데이터셋        | 명목 95% | 실제 커버리지
Friedman 1      |   95%    |   93.2%
Boston Housing  |   95%    |   94.8%
California      |   95%    |   92.1%
```

대체로 명목 수준에 가까운 커버리지를 보이지만, 일부 데이터셋에서는 약간의 과소 커버리지가 관찰된다. 이는 유한 표본 효과와 정규 근사의 한계 때문이다.

## 7. 실용적 구현

### 7.1 Python에서의 IJ 분산 추정 (개념적)

```python
import numpy as np
from sklearn.ensemble import RandomForestRegressor

def ij_variance(rf_model, X_train, X_new):
    """
    무한소 잭나이프 분산 추정 (개념적 구현)
    """
    n_samples = X_train.shape[0]
    n_trees = len(rf_model.estimators_)

    # 각 트리의 예측
    tree_predictions = np.array([
        tree.predict(X_new) for tree in rf_model.estimators_
    ])  # (n_trees, n_new)

    # 앙상블 평균
    mean_pred = tree_predictions.mean(axis=0)

    # 각 샘플이 각 트리에 몇 번 포함되었는지 (근사)
    # 실제로는 estimators_samples_ 사용

    # IJ 분산 계산
    variances = np.zeros(X_new.shape[0])

    for i in range(n_samples):
        # 샘플 i의 영향
        in_tree = np.array([
            1.0 if i in rf_model.estimators_[b].tree_.n_node_samples
            else 0.0
            for b in range(n_trees)
        ])
        cov_i = np.mean(
            (in_tree - in_tree.mean())[:, None] *
            (tree_predictions - mean_pred[None, :]),
            axis=0
        )
        variances += cov_i ** 2

    return variances
```

### 7.2 forestci 패키지

Python에서는 `forestci` 패키지가 IJ 분산 추정을 구현하고 있다:

```python
import forestci as fci

# IJ 기반 분산 추정
V_IJ = fci.random_forest_error(rf_model, X_train, X_test)

# 95% 신뢰구간
predictions = rf_model.predict(X_test)
lower = predictions - 1.96 * np.sqrt(V_IJ)
upper = predictions + 1.96 * np.sqrt(V_IJ)
```

## 8. 핵심 요약

### 본 논문의 핵심 기여

1. 랜덤 포레스트 예측에 대한 **통계적으로 유효한 신뢰구간**을 구성하는 이론적 기반을 확립하였다.
2. **무한소 잭나이프(IJ)** 분산 추정량으로 효율적으로 분산을 추정할 수 있다.
3. 변수 중요도에 대한 **형식적 가설 검정**이 가능해졌다.
4. 신뢰구간의 **보정 특성**이 실험적으로 검증되었다.

- 금융: 리스크 평가에서 예측의 신뢰도를 정량화
- 환경 과학: 기후 모델 예측의 불확실성 범위 제시
